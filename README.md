# 📊 Análise de Vendas com Python

## 📌 Sobre o projeto

Este projeto realiza uma análise exploratória de dados de vendas, com o objetivo de extrair insights relevantes para tomada de decisão.

## 🚀 Tecnologias

* Python
* Pandas
* Matplotlib

## 📁 Dataset

O dataset contém informações sobre vendas, incluindo:

* Data
* Produto
* Categoria
* Quantidade
* Preço unitário

## 🔍 Análises realizadas

* Cálculo do faturamento total
* Identificação dos produtos mais vendidos
* Análise de faturamento por categoria

## 📊 Resultados

* Eletrônicos lideram em faturamento
* Produtos de alto valor têm maior impacto na receita
* Categorias com alto volume nem sempre geram maior lucro

## 🧠 Aprendizados

* Manipulação de dados com Pandas
* Agrupamento e agregação de dados
* Visualização com Matplotlib
